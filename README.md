# Mathos Contabilidade · link da bio

Página do link da bio do Instagram @mathoscontabilidade. Publicada em https://bio.mathoscontabilidade.com.br.

Site estático, sem build:

- `index.html`: a página, com atalhos pro WhatsApp com mensagem pronta para cada caso (MEI, Simples Nacional, abrir empresa, trocar de contador), site, telefone e o cartão do Hugo
- `hugo.webp`: foto do Hugo
- `og.jpg`: imagem de prévia do link
- `favicon.svg`: ícone da aba

WhatsApp, telefone, site, link do cartão e horário ficam no objeto `CONTATO`, no começo do `<script>` em `index.html`. As mensagens de cada botão ficam no atributo `data-wa` de cada link.
